### 🛠️ 윈도우 오류로 스트레스받으시나요? AI 기반 'Windows Fix Wizard'로 1초 만에 해결하세요!

컴퓨터를 사용하다 보면 원인을 알 수 없는 **블루스크린(BSOD)**, **윈도우 업데이트 오류(0x800f081f, 0x80070002 등)**, **네트워크 연결 끊김**, **마이크로소프트 스토어 다운로드 실패** 등 다양한 문제에 직면하게 됩니다.

인터넷에서 해결 방법을 검색하면 수많은 명령어와 복잡한 블로그 글이 나오지만, 내 컴퓨터 버전에 맞지 않거나 검증되지 않은 명령어로 인해 오히려 시스템이 더 엉키는 경우가 많습니다.

이러한 불편함을 완벽하게 해결하기 위해 개발된 **Windows Fix Wizard (윈도우 문제 해결 마법사)**를 소개합니다!

---

### 💡 Windows Fix Wizard 주요 핵심 기능

1. **🤖 Google Gemini AI 기반 실시간 증상 진단**
   - 오류 코드(예: `0x80070005`)나 오류 증상("윈도우 업데이트가 99%에서 멈춰요")을 입력하면, AI가 원인을 정밀 분석하여 맞춤형 해결책을 즉시 제공합니다.
   - 마이크 음성 인식(Web Speech API) 기능을 지원하여 직접 타이핑하지 않고 음성으로 편하게 증상을 말할 수 있습니다.

2. **⚡ 검증된 PowerShell 자가치료 스크립트 자동 생성**
   - 원클릭으로 안전하게 실행할 수 있는 PowerShell 관리자용 명령어가 자동 생성됩니다.
   - 복사 버튼 한 번으로 원클릭 복사하거나 디지털 서명이 완료된 스크립트를 즉시 다운로드할 수 있습니다.

3. **🔍 윈도우 공지/Known Issues 데이터베이스 검색 Engine**
   - Microsoft 공식 데이터베이스 및 알려진 오류(Known Issues) 지식베이스를 실시간으로 검색하여 100% 검증된 복구 가이드를 제공합니다.

4. **🛡️ 악성 파일 및 보안 위협 검증 (Threat Verifier)**
   - 의심스러운 `.exe`, `.dll`, `.bat` 파일이나 스크립트의 해시(SHA-256) 및 보안 위험도를 미리 진단하여 시스템 손상을 예방합니다.

5. **🚀 시작프로그램 등록 및 바탕화면 바로가기 지원**
   - 자주 사용하는 사용자를 위해 클릭 한 번으로 바탕화면 바로가기(.url) 생성 및 윈도우 부팅 시 자동 실행 등록 스크립트를 제공합니다.

---

### 📖 사용 방법 (3단계 초간단 가이드)

1. **[웹 서비스 접속]** [Windows Fix Wizard 웹사이트](https://ahbiyout-all.github.io/windows-fix-wizard/)에 접속합니다. (별도 설치 없이 웹 브라우저에서 즉시 실행)
2. **[증상 입력 또는 검색]** 검색창에 오류 코드나 증상을 입력하거나 마이크 버튼을 눌러 음성으로 증상을 말합니다.
3. **[스크립트 실행 및 복구]** AI가 추천하는 해결 스크립트를 복사하여 Windows PowerShell(관리자 권한)에 붙여넣고 실행하면 오류 해결 완료!

### ❓ 자주 묻는 질문 (FAQ)

- **Q. 무료로 사용할 수 있나요?**
  - 네! Windows Fix Wizard는 100% 무료로 제공되는 오픈소스 웹 서비스입니다.
- **Q. PowerShell 스크립트를 실행해도 안전한가요?**
  - 시스템 변경 전 복원 지점 생성 및 안전성 검증 코드가 포함되어 있으며, 실행 전 전체 코드를 검토할 수 있어 안전합니다.
