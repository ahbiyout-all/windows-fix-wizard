# 📝 구글 블로거 (Google Blogger / Blogspot) 공식 포스팅 통합 가이드

본 문서는 **Windows Fix Wizard (윈도우 문제 해결 마법사 v3.50.0)** 서비스를 구글 블로거(Google Blogger / Blogspot)에 공식 홍보 및 소개하기 위한 종합 관리 템플릿입니다.

블로거의 에디터 작성 모드에 맞추어 아래의 전용 문서를 사용하세요:

1. **[작성 모드 (서식 있는 텍스트)] 전용 문서**: [`docs/BLOGGER_COMPOSE_MODE.md`](./BLOGGER_COMPOSE_MODE.md)
   - 블로거 기본 비주얼 에디터에 그대로 드래그 & 복사/붙여넣기(Ctrl+V)하여 즉시 발행 가능한 문서입니다.
2. **[HTML 편집 모드 (`<>`)] 전용 문서**: [`docs/BLOGGER_HTML_MODE.md`](./BLOGGER_HTML_MODE.md)
   - 모바일 반응형, 다크/라이트 현대식 카드 디자인, 앱 UI 목업, 다운로드 버튼이 포함된 인라인 HTML 코드 블록입니다.
